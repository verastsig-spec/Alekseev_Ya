Training Planner (План тренировок)

Автор
**Имя и фамилия:** Алексеев Ярослав 
**Дата создания:** Апрель 2026

Описание
Графическое приложение на Python (`tkinter`) для планирования и учёта тренировок. 
Позволяет добавлять записи с датой, типом и длительностью, фильтровать их, а также сохранять и загружать данные в формате JSON.

Возможности
- Валидация ввода: проверка формата даты (`ГГГГ-ММ-ДД`) и положительной длительности.
- Отображение записей в табличном виде.
- Фильтрация по типу тренировки и конкретной дате.
- Экспорт/импорт данных в `workouts.json`.
- Современный интерфейс на базе `ttk`.

Инструкция по запуску
1. Убедитесь, что установлен **Python 3.6+**.
2. Скачать репозиторий, определить все папки из проектав какую-то одну и открыть ее через любое IDE.
