Training Planner (План тренировок)

Создать GUI-приложение «Training Planner» для планирования тренировок с фильтрацией, JSON и Git.

Пошаговая инструкция:

1. Создайте форму с полями:

○ Дата

○ Тип тренировки

○ Длительность

2. Добавьте кнопку «Добавить тренировку», которая добавляет запись в таблицу.

3. Реализуйте фильтрацию:

○ По типу тренировки

○ По дате

4. Сохраняйте и загружайте данные через JSON.

5. Проверяйте корректность ввода:

○ Дата — в правильном формате.

○ Длительность — положительное число.

6. Используйте Git:

○ Создайте репозиторий.

○ Добавьте .gitignore.

7. Напишите README (в формате .txt, .md или .docx), в котором укажите:

○ Имя и фамилию автора

○ Описание

○ Примеры использования (возможные тесты — по желанию)
